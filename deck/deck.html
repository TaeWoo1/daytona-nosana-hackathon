Product, next steps, limits

Product

  • Point it at your page: every AI reader × every layout, graded against your own answer key
  • Shows which fact breaks and for which model, with replayable screenshots

Next

  • Commerce pages, e.g. Naver Smart Store product pages: options and prices behind tabs and selectors
  • CI check: "does this layout change break any AI reader?"
  • Auto-fix suggestion per failing fact

Limits

  • One page, reproduced layouts (not the live site), q1 for the browser runs
  • Small n: A 10 reps/model, C 5 reps/model; directional, not proof
  • Computer use is n=1
  • OpenAI excluded (no API credits)

Appendix Judging criteria

Completeness

  • End-to-end: real page → gold → layouts → Daytona sandboxes → reader agents → code grader → dashboard, stage, deck
  • 521 graded runs committed in results/, so every number can be checked without rerunning

Innovation

  • Measures comprehension accuracy (does the agent get the facts right?), not search visibility
  • Reading mode as a dimension: crawler text, static visible text, real browser with click, computer use (n=1)

Real-Life Problem Solving

  • Layout reproducing daytona.io/pricing: runs with no click were correct 0/10; 12/33 runs confident wrong
  • Same facts, explicit layout C: 20/20 correct

Sponsored Product Usage

  • Daytona: 32 ephemeral sandboxes; Chromium + every tool call inside the sandbox; computer-use desktop + recording

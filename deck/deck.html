Dashboard
  • Same system prompt and one tool, open_page(path), for every model. Temperature 0. Strict JSON answer + evidence quote + not_found.
  • Two reader modes: html_text (all HTML text, like a crawler) and visible_text (hidden elements dropped, a static approximation of a browser view).
  • Control: No page, where the model answers from memory.

Method and metrics

  • Gold answers from the real page, 5 questions: GPU on-demand trap, CPU cost with "first 5 GiB free", card / free credit, billing unit, Windows price.
  • Per run: each field is graded correct / not found / wrong / invalid. A confident wrong value is worse than "not found".
  • Field accuracy, evidence reach (did the gold text appear in the tool output?), and the headline worst-model accuracy per layout.
  • 3 reps per cell. Small n, so we say "in these runs", not "proven".

Sponsor usage

Daytona

  • 10 ephemeral sandboxes across runs, each serving one layout on localhost:8000
  • 325 open_page calls executed inside sandboxes (median 0.31s each), with a fresh process per call and no shared state
  • Parallel fan-out: layouts × workers, all runs from one script

Nosana

  • 3 open-weight reader models on decentralized GPUs: Qwen 3.5 9B (RTX 3090), gpt-oss 20B and Gemma 4 26B (RTX 4090)
  • 214 graded reader runs served from Nosana
  • Small open models are exactly the readers that need a robust layout

Counts from results/runs*.jsonl. Graded runs total: 319.

Limitations and next steps

  • One page, a simplified mirror (A), 3 reps per cell. Directional, not proof.
  • visible_text is a static approximation. Next: a real browser / Computer Use reader inside Daytona.
  • Field accuracy gives partial credit. See the per-question "fully correct" view.
  • OpenAI excluded: the API key had no credits ({"openai: RateLimitError": 60}).
  • Gold ambiguity: "first 5 GiB free" per sandbox or per org? (Both readings are inside the q2 tolerance.)
  • Next: more pages and verticals, an auto-fix suggestion per failing fact, and a CI check: "does this layout change break any AI reader?"
